# QA-AI-Ecosystem-Training 🚀

Репозиторій для фіксації практичного досвіду в рамках навчання за напрямком Manual QA. Під час курсу мною було спроєктовано та розгорнуто автономну тренувальну AI-екосистему для симуляції реального циклу розробки, тест-дизайну та проходження технічних співбесід.

## 🏗️ Архітектура Екосистеми (ChatGPT Projects)
1. **QA_Bug_Injector (Агент-Розробник):** Генерує технічні вимоги (ТЗ) з прихованими логічними дефектами, невалідними масивами даних та граничними помилками (Bug Seeding).
2. **Senior_QA_Reviewer (Агент-Ментор):** Проводить рев'ю моїх тест-кейсів, чек-листів та баг-репортів на відповідність стандартам ISTQB, виставляючи оцінку якості документації.
3. **QA_Tech_Lead_Interviewer (Агент-Інтерв'юер):** Симулює технічні співбесіди на позицію Junior QA на основі пройдених тем курсу та допущених мною помилок.

## 📂 Структура репозиторію
* `/theory_interviews/` — Логи симуляцій технічних співбесід та бліц-опитувань.
* `/test_design/` — Вимоги від AI-розробника, створені чек-лісти та тест-кейси для них.
* `/bug_reports/` — Оформлені баг-репорти та результати аудіту документації від Senior AI-агента.
* `/api_sql/` — Логи тестування API (Postman) та практичні SQL-запити до баз даних.
